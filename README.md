# EduLectures — Образовательная веб-платформа

Веб-платформа для поиска лекторов, ознакомления с учебными дисциплинами и записи на консультации. Проект выполнен в рамках лабораторной работы по дисциплине «Разработка пользовательских интерфейсов».

## Команды для установки и запуска

### 1. Клонирование репозитория
```bash
git clone https://github.com/Shonni123/Faizrahmanova_RPI_laba3.git
cd Faizrahmanova_RPI_laba3
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
После запуска проект доступен в браузере по адресу:
`http://localhost:5173/`

Для запуска на ОС Windows также предусмотрен скрипт `start.bat`.

### 4. Сборка проекта
```bash
npm run build
```
Файлы оптимизированной сборки сохраняются в директорию `dist/`.

### 5. Предпросмотр сборки
```bash
npm run preview
```

## Данные и роутинг

### 1. Расположение данных (`src/data/`)
Все данные платформы вынесены в директорию `src/data/`:
* `src/data/lecturers.js` — массив преподавателей (ФИО, должность, ученая степень, опыт работы, контактная информация, пол, фото и список тем лекций).
* `src/data/partners.js` — массив вузов и технологических компаний-партнеров (название, категория, описание, ссылка).
* `src/data/index.js` — модуль централизованного экспорта данных для удобного импорта в компоненты.

### 2. Организация роутинга (`src/App.jsx`)
В приложении используется клиентская маршрутизация на основе локального состояния (State-based SPA):
* Текущий активный экран определяется состоянием `activeTab` в корневом компоненте `App.jsx`.
* Доступные вкладки:
  * `home` — главная страница;
  * `partners` — страница партнеров;
  * `about` — информация о платформе;
  * `lecturers` — каталог преподавателей с фильтрами;
  * `courses` — каталог дисциплин.
* Переключение разделов осуществляется через компонент `Header` вызовом функции `handleTabChange`.
* Реализован переход со страницы дисциплин к конкретному преподавателю: при клике на дисциплину в `CoursesPage` происходит переключение вкладки на `lecturers`, автоматическое раскрытие списка тем выбранного лектора и плавный скролл к его карточке.
